# Catalogue data and source rights

NoveList stores catalogue metadata in the installation's `backend/data/catalogue.db`. The database, legacy JSON imports, cached covers, and generated index artifacts are excluded from Git and Docker images. The app does not download or serve novel chapters. It can store descriptions and source URLs, fetch and cache cover images, and display that content to readers.

A public page is not a blanket reuse license. Descriptions and cover art may be protected expression; database collections and site terms can impose separate restrictions. The [U.S. Copyright Office](https://www.copyright.gov/help/faq/faq-protect.html) distinguishes factual titles from protected expression, and the [EU Database Directive](https://eur-lex.europa.eu/legal-content/EN/ALL/?uri=CELEX%3A31996L0009) addresses extraction and reuse of database contents. Storing material in SQLite instead of a Git repository changes distribution of the repository, but does not settle the rights to show it on a site.

The previous catalogue included links to Royal Road, Goodreads, NovelFull, NovelFire, and Webnovel, plus records entered or merged locally. The repository cannot establish permission for every description or image in that collection. In particular, [Goodreads' Terms of Use](https://www.goodreads.com/about/terms) exclude collection and use of its book listings and descriptions and restrict automated extraction. NoveList no longer offers a Goodreads collection adapter or accepts Goodreads pages through custom metadata collection. Existing local records were preserved for review, not declared cleared for public use.

Before a public launch, review each source's current terms and any content or image license; record what can be stored, displayed, cached, attributed, and refreshed. Remove or replace records that lack a supported use basis. Keep the source URL on each record and honor removal requests. The operator controls `COVER_EXTRA_HOSTS`; adding a host permits the server to fetch from it but does not grant content rights.
